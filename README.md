# OEM Diagnostic Assistant

Persian RTL product design prototype for an Android POS diagnostic assistant.

Run the prototype by opening index.html in a modern browser, or serve the directory with `python3 -m http.server 8080`.

This prototype uses simulated diagnostic results. It does not connect to POS hardware, payment systems, SDKs, or cloud AI. No payment data should be entered.

The interface implementation is developed on a separate branch and submitted for review.
